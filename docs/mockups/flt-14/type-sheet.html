FLT-14 · Display type options (headings and numbers only; body stays Nunito for legibility)

Left: Jem's pick, Chalmers by Pretend Foundry, shown from the foundry's own specimen (paid: $10 per style + web license, not bought). Right: free OFL pixel faces rendered live, for comparison.

Watch-out for numbers. In Pixelify Sans, 5 and S are nearly identical (“5.8MO” reads “S.8MO”, “$25K” reads “$2SK”). A money-and-stats HUD needs unambiguous digits, so for numbers prefer Jersey 10, Handjet, or Chalmers (check its 5/S in the specimen before buying). Any of them pairs with Nunito for body text.

Cost if Jem picks Chalmers: 1–2 styles (e.g. Bricked + Bricked Slanted) × $10, web license, bought by Jem. The free fallback ships until then.
